Temperature Converter

Description

The Temperature Converter is a Python program that converts temperatures between Celsius, Fahrenheit, and Kelvin. It uses separate functions for each conversion and displays the results neatly.

Features

- Converts Celsius to Fahrenheit and Kelvin.
- Converts Fahrenheit to Celsius and Kelvin.
- Converts Kelvin to Celsius and Fahrenheit.
- Uses functions for calculations.
- Validates user input.
- Displays results up to two decimal places.

Conversion Formulas

- Celsius to Fahrenheit: (C × 9/5) + 32
- Celsius to Kelvin: C + 273.15
- Fahrenheit to Celsius: (F − 32) × 5/9
- Fahrenheit to Kelvin: (F − 32) × 5/9 + 273.15
- Kelvin to Celsius: K − 273.15
- Kelvin to Fahrenheit: (K − 273.15) × 9/5 + 32

Requirements

- Python 3.x

How to Run

1. Save the program as "temperature_converter.py".
2. Open the terminal or VS Code.
3. Run "python3 temperature_converter.py".
4. Select a conversion option and enter the temperature.
